The help text id is scoped to the plugin and the filter row, otherwise multiple search plugins (or filters) on one page would produce duplicated ids and break the aria-describedby reference (WCAG 1.3.1 / 4.1.2). The value is pre-filled again from the request, so the search word never has to be entered twice (WCAG 2.2 - 3.3.7 Redundant Entry).
